2. Complete Project Bootstrapping Sequence

Step 1: Scaffold fresh React application using Vite
npm.cmd create vite@latest nextgen-app -- --template react cd nextgen-app
Step 2: Install UI dependencies and Lucide icon library
npm.cmd install lucide-react
Step 3: Install Capacitor native core and CLI tools
npm.cmd install @capacitor/core npm.cmd install -D @capacitor/cli
Step 4: Initialize Capacitor config (App Name & Package ID)
npx.cmd cap init "NextGen" "com.indabamenscorner.nextgen" --web-dir dist
Step 5: Install native hardware and storage plugins
npm.cmd install @capacitor/geolocation @capacitor-community/contacts @capacitor/preferences npm.cmd install @capacitor/android
Step 6: Inject Android native platform directory
npx.cmd cap add android

3. Daily Development & Live Hot-Reload Workflow

Run local development server with instant HMR:
cd C:\nextgen-app npm.cmd run dev

Accessible locally at http://localhost:5173/

4. Production Build & Native Sync Sequence

Execute these two commands whenever changes are made to src/App.jsx or public assets:

1. Compile optimized web assets into /dist folder:
npm.cmd run build
2. Copy dist bundle and sync native plugin configurations to Android Studio:
npx.cmd cap sync android

5. Android Studio Launch & CLI Release Packaging

Option A: Open the native project directly inside Android Studio GUI:
npx.cmd cap open android
Option B: Build production APK directly from terminal (No GUI required):
cd C:\nextgen-app\android .\gradlew.bat assembleRelease
Option C: Build Google Play Store production bundle (.aab):
cd C:\nextgen-app\android .\gradlew.bat bundleRelease
Inspect output directory in Windows Explorer:
explorer.exe app\build\outputs\apk\release

6. Android Permissions & Native Manifest Rules

Configured in android/app/src/main/AndroidManifest.xml:
  • android.permission.ACCESS_FINE_LOCATION - High-precision GPS for Family SOS beacons
  • android.permission.ACCESS_COARSE_LOCATION - Cellular tower positioning fallback
  • android.permission.READ_CONTACTS - Local address book discovery for safe friends chat
  • android.permission.INTERNET - WebView asset delivery and external social handoffs

8. Full System Reset & Clean-Build Procedures

If Gradle hangs, dependencies conflict, or Vite exhibits caching errors, run this exact sequence:

1. Purge Gradle cache and build artifacts:
cd C:\nextgen-app\android .\gradlew.bat clean cd ..
2. Reinstall Node modules cleanly:
rmdir /s /q node_modules del package-lock.json npm.cmd install
3. Re-bundle and re-sync native bridge:
npm.cmd run build npx.cmd cap sync android

10. Key Architecture Checkpoints to Remember

  • POPIA Data Privacy: User reflections, budget states, and dilemma votes must stay in @capacitor/preferences. Never transmit minor data to unauthenticated servers.
  • Social Handoff Deep-Links: Uses WhatsApp (https://wa.me/<phone>?text=...), Instagram (https://instagram.com/direct/inbox/), and Messenger (https://m.me/).
  • Inner Companion Personas: Controlled in COMPANION_GRADE_PERSONAS dictionary in src/App.jsx. Easily adjust copy for different grades or school campaigns.
